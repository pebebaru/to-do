# to:DO design system

The current visual source is the existing Stitch project **to:DO Execution Assistant**, project `14022038490439074691`. Original screen HTML, screenshots, and screen metadata are preserved in `design/stitch/` for review. The React application implements the reference styling around the original product behavior.

Use the exact Stitch tokens: canvas `#111318`, deepest surface `#0c0e13`, low surface `#1a1b21`, container `#1e1f25`, high surface `#282a2f`, highest surface `#33353a`, action `#4d8eff`, action text `#00285d`, primary accent `#adc6ff`, primary text `#e2e2e9`, secondary text `#c2c6d6`, outline `#8c909f`, outline variant `#424754`, success `#4edea3`, error `#ffb4ab`, and tertiary `#ffb95f`. Personal uses green, Work uses blue. The mobile critical dispatch follows the reference's red gradient, red border and glow, and white Start Focus button.

Plus Jakarta Sans supplies headings, Inter supplies body text, and JetBrains Mono supplies timing and small labels. Actual variable font files support the requested weights, including 600/700 headings and 400/500/600 body text. Fonts and their OFL licenses are bundled locally in `src/app/fonts/`; no external font fetch is required at runtime or build time. Desktop hero typography is 26px/34px at weight 700, mobile dispatch is 20px/28px at weight 700, body is 14px/22px, and mono labels are 11px/16px. Desktop stopwatch typography is 56px/64px with -0.04em tracking.

Desktop follows the 256px sidebar, 64px header and 3/6/3 command-center columns: Day Flow on the left; dispatch, capture and queue in the center; rituals, waiting and telemetry on the right. Gaps are 14px and panel corners 12px. Focus Tunnel dims and blurs secondary panels, revealing them on hover or keyboard focus; Cmd/Ctrl+B toggles it. Tablet reflows columns. Mobile uses five-item bottom navigation and a red critical dispatch. The editor follows the darker `#141720` modal and `#2a3348` borders, with priority cards and a bold title. Schedule supports date navigation and Day/3-Day/Week grids with actual blocks and overlap notices. Quick capture parses @work/@personal, #p1–#p3, ~minutes, and !today/!tomorrow/!YYYY-MM-DD.

Focus follows the reference's ring stopwatch, micro-step, Pause, +10 Mins, Next Step, completion, and urgent interruption controls. Interruption pauses the clock and can park a thought in Inbox then resume. Actual time remains an elapsed stopwatch. Keyboard focus is visible; reduced-motion is respected. Hover controls never change task-row height.

The Stitch colon/chevron mark is `public/mark.svg`; the supplied full wordmark is `public/stitch-logo.svg`. App identity is shared through `src/lib/brand.ts`. Product capitalization is **to:DO**. Telemetry and Focus Analytics display actual task counts and logged time. Network latency, database pool statistics, focus streaks, and fake production health are not invented. Empty schedules and rituals reflect real data. Manual ordering continues to govern recommendations.
